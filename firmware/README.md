# firmware/ — прошивки на ESP-IDF

Новые прошивки обеих плат на чистом ESP-IDF (без Arduino). План и требования — в [`../TZ_ESP-IDF_Sebastian.md`](../TZ_ESP-IDF_Sebastian.md).

| Папка | Плата | Статус |
|---|---|---|
| `head/` | ESP32-S3-N16R8 (голова) | пусто, ждёт фазу 0 |
| `coproc/` | ESP32 D0WD-V3 (со-процессор) | пусто, ждёт фазу 0 |
| `common/` | общий протокол UART | появится в фазе 0 |
| `tools/` | `ota_upload.py` и обёртки для Windows | появится в фазе 0 |

Старые Arduino-прошивки — в `../ESP32_Sebostian/`. Их **не удалять**: это аварийный откат по кабелю.

⚠️ Первая прошивка на IDF у каждой платы — **только по кабелю** (разметка флеша другая, с Arduino по Wi-Fi на неё не перейти). Откат на Arduino — тоже только кабелем.

⚠️ Путь к проекту на Windows — **без пробелов и кириллицы** (ESP-IDF на них ломается). Например `C:\dev\SEBOSTIAN`, а не `C:\Users\...\Рабочий стол\...`.
