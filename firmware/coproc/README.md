# coproc — со-процессор (ESP32 D0WD-V3) на ESP-IDF v5.5.5

Как залить и проверить — в [`../README.md`](../README.md). Эталон поведения — Arduino v7.2 (`../../ESP32_Sebostian/ESP32`).

| Файл `main/` | Что |
|---|---|
| `main.c` | старт, сенсоры/кнопка, статус голове 5 раз/с, NVS |
| `board.h` | пины и пороги батареи (`BAT_CAL_MV` — поправка АЦП) |
| `btaudio.c` | A2DP «Sebastian» (Bluedroid, SSP без PIN) -> I2S0 -> PCM5102A; писк и «Ода к радости» |
| `led.c` | лента WS2812 на RMT: 6 режимов, радуга, вспышки |
| `rf433.c` | радио 433 как RCSwitch (протокол 1, 389 мкс, 24 бита, ×8): приём по прерываниям, передача RMT, HOLD = код #1 ×3 |
| `battery.c` | АЦП с калибровкой, среднее 10 с, сон/пробуждение, окно «ВКЛЮЧИТЬ» |
| `link.c` | UART2 к голове (PING, BEEP, MUSIC, LED, RF, RFHOLD, OTA, SLEEP, FORCE, CFG) |
| `otamode.c` | режим прошивки: BT выкл -> Wi-Fi -> POST /ota, статус `W,...` голове, 5 мин |

Wi-Fi и пароль OTA со-процессор получает от головы строкой `CFG` (хранит в NVS).
